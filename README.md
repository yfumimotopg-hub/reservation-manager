# Simple Reservation Manager

React / TypeScript / FastAPI を用いた会議室予約管理システムのポートフォリオです。

## 作成目的

エンジニアとしての基礎力を示すため、業務システムを想定した予約管理アプリケーションを作成します。

## 主な機能

- ログイン
- ユーザー管理
- 権限管理
- 会議室予約の登録・編集・削除
- 予約一覧表示
- 検索・絞り込み
- 入力バリデーション
- APIエラーハンドリング
